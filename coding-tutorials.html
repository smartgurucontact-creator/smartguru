💻 Coding Tutorials

Learn coding and website development step by step, starting from zero.

1. HTML kya hai?

HTML website ka structure banane ke liye use hota hai. Isse headings, paragraphs, images aur links add karte hain.

<h1>Hello World</h1>
<p>My first website</p>

2. CSS kya hai?

CSS website ko design karta hai. Isse colors, backgrounds, fonts aur layout change kar sakte hain.

h1 {
  color: blue;
}

3. JavaScript kya hai?

JavaScript website mein functionality aur interaction add karta hai.

alert("Welcome to Smart Guru!");

4. Apni pehli website

HTML, CSS aur JavaScript ko use karke ek simple website banayi ja sakti hai.

  • HTML — Structure
  • CSS — Design
  • JavaScript — Functionality

5. Website online kaise karein?

Website ke files ko Netlify jaise hosting platform par publish karke internet par accessible banaya ja sakta hai.
